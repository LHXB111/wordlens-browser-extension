三步开始使用

  1. 保存你偏好的查询方式。无需 API Key 时可以先用免费英文词典。
  2. 刷新已打开的网页，然后用鼠标选中一个英文单词。
  3. 阅读释义、点击发音按钮，或把它收藏进生词本。

接入 AI

在「偏好与 API」选择 AI 详解，填写服务商的 API Key、API 地址和账号可用的模型名，再点击「测试连接」或「保存设置」。首次使用该地址时，浏览器可能会要求允许访问此服务。

支持返回 choices[0].message.content 的 Chat Completions 兼容接口。自定义可接入支持此协议的服务商或本地模型服务；原生 Claude / Gemini 接口需要兼容网关。

阅读小技巧

  • Alt + T：查询当前选中文字。快捷键冲突时可在浏览器的扩展快捷键页修改。
  • Esc：关闭浮窗。点击空白处也可以关闭。
  • 按住浮窗顶部「拾词」标题栏拖动，松开即可停在新位置。查询新文字时回到选区旁。
  • 拖动浮窗四边或四角调整大小；双击右下角恢复默认大小。当前网页会记住所调整的尺寸。
  • 固定按钮：滚动网页时保留浮窗；再次点击取消固定。
  • 右键选中文字 → 用拾词解释。
  • 免费词典查询英文单词；AI 可以处理短语、句子和多语言文本。

没有出现浮窗？

确认划词开关已开启、网站未列入暂停列表，然后刷新网页。Chrome / Edge 设置页、扩展商店和浏览器内置 PDF 阅读器不能注入普通内容脚本。输入框、密码框、网页编辑器不会触发查询；需要解释时可粘贴到工具栏弹窗里。

数据与费用

密钥和生词本使用浏览器本地存储，卸载扩展会清除这些数据。密钥未加密，适合个人本机使用；请只填入可信的接口地址。默认只发送选中文字，开启语境后会额外发送附近文本；浏览器朗读使用系统或浏览器提供的语音。AI 请求费用由你的 API 服务商收取，测试连接也会调用一次 API。最多保存 500 条收藏，可随时导出 CSV。
